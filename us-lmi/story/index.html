A New Map of Work

Start from O*NET, then add posting evidence.

O*NET is the standard U.S. taxonomy for describing work. Interviews with workers in occupations produce task statements; occupation experts connect those tasks to broader work activities and back to occupations. That gives the official map. Posting evidence lets us ask where those same task statements also appear in current hiring, and which added links are plausible enough to keep.

Analyzing the Mismatch

Not every new link means the same thing.

Once the posting-derived map differs from the O*NET map, the task is to sort what the differences mean. Some off-list pairs look like missing core work. Some are broad, general tasks. Some depend on whether the posting occupation was coded correctly. The dashboard keeps those distinctions visible instead of treating every off-list pair as the same kind of finding.

Finding Emerging Skills

Building Maps of Emerging Skills

The broader problem is that standard taxonomies often lack the task and skill statements needed to describe emerging work. AI is the example here: postings supply candidate language, then the measurement problem becomes which statements are clearly AI-related, which are adjacent, and how reliable the resulting intensity score is.

The result is not a final ontology. It is a validated way to build and inspect provisional maps of emerging skills from observed posting text.

See Meisenbacher and Norlander (2026), “Building a Custom Taxonomy of AI Skills and Tasks from the Ground Up with Job Postings”, Proceedings of the 2nd Workshop on Customizable NLP (CustomNLP4U), forthcoming, arXiv:2605.21029, for the taxonomy-construction approach used to organize posting-derived task and skill sentences.

Dynamic Maps

Building dynamic maps.

The final step is to track change over time. See reviewed task links, ESCO skills, and a STEM task bundle move through occupational space. We use LLMs to review candidate task-occupation matches suggested by postings, to validate a measure of AI intensity in postings, and to identify the bundle of STEM-related task statements.

These movies are exploratory: occupation coding has measurement error, and the national posting corpus changes in ways we cannot fully observe.

Limitations

These demonstrations show the power of the Job Ad Analysis Toolkit (JAAT) and computational procedures to retrieve standard and structured skill data from postings. Findings and the dashboard are exploratory and have many limitations: standard taxonomies have gaps, postings have limitations, occupation coding has measurement error, and users should apply judgement for specific use cases. NLx-based views use aggregate evidence; raw NLx posting text is not public. For more information, see NLx Research Hub.
