Occupational Posting Profile

Select one 8-digit O*NET-SOC occupation. Tables use USAJOBS task, skill, Work Activity, and ConceptSearch aggregates.

How to read this page. This is a federal posting profile, not a national occupation profile. RCA highlights distinctive rows within USAJOBS; frequency columns show scale. ConceptSearch rows are descriptive matches, while task rows use the occupation-task agreement procedure.

This profile is the USAJOBS occupation posting profile for the selected 8-digit O*NET-SOC occupation. Task tables use rows retained by the job-ad-derived occupation-task pair two-model agreement procedure; RCA highlights tasks that are distinctive for the occupation, while the frequent-task table shows the tasks most prevalent in postings. Tools, technologies, education, and benefits are supporting concept features, not task agreement evidence.

Shared terms. % posts = share of selected occupation postings with the row. RCA = row share in the selected occupation / row share in USAJOBS overall. In O*NET = 1 when O*NET lists the selected occupation-task pair.
