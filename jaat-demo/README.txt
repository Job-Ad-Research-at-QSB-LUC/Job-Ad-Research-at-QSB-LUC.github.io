JAAT companion: From job postings to workforce information with open tools

Start at index.html. The homepage page index links results, demonstrations, code and data described in the manuscript and SI Appendix.

Relatedness results use NLx occupation-task profiles; the public USAJOBS notebooks demonstrate the workflow using federal postings. Reconstructing NLx profiles requires authorized access. Released summaries and inputs support the calculations described in each resource's documentation.

Incident-linked task displays release at most five occupation examples per task. Display limits do not change the underlying benchmark results. Incident linkage does not establish that a task caused an injury or estimate an individual worker's risk.

Website layout and explanatory text were prepared with generative-AI assistance. Model methods, review protocols, source versions and code are provided with the relevant resources.
