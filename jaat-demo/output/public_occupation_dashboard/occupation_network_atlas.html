    Methods and public data access

    Occupation rankings and aggregate statistics use the complete corrected research data. Identifiable tasks include each occupation’s O*NET-linked tasks, retained posting assignments accepted in completed review, and retained unreviewed assignments with support above 200 sampled job-months. Other assignments have not been reviewed; their task details are not released. The network includes only links between permitted tasks; this can change its connected components.

    Anonymous cloud dots preserve the number of additional linked tasks, coarse size bands. Their positions are synthetic and do not encode task identity or relatedness. Individual IDs, statements, exact frequencies, and links for these dots are not distributed.

    Similarities describe advertised work, not observed worker moves or a person’s qualifications. Sample units are job-months, not annual unique vacancies. Recorded .00 base profiles may include mechanically suffixed unspecified six-digit source labels; released aggregates cannot separate them. Missing released links are unknown. Six-digit maps sum only available released specialty links, leaving below-threshold pairs unobserved. See methods, attribution, and interpretation.
