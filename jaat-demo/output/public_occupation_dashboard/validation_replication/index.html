Occupation explorer · Methods

Code and data for the transition comparison

Recalculate the paper’s comparison with observed occupational transitions in Python or Stata. The download includes occupation rankings, transition totals and the values used to calculate recovery.

Download code and data · ZIP

For each starting occupation, both models recommend the same number of destinations, up to 20. This is the paper’s “equal-length” comparison. The package recalculates results from saved rankings; rebuilding the models requires the separate construction code and restricted inputs. The paper uses the three-year NLSY97/PSID horizon; five- and ten-year results are also included.

Run the analysis

Python: python replicate.py . results (requires pandas). Stata: set this folder as the working directory and run do replicate.do.
