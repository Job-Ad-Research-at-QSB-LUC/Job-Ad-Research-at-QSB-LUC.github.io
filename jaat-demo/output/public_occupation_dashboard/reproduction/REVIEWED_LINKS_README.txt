CURRENT OCCUPATION–TASK REVIEW RESULTS
45,487 distinct occupation–task links with YES/NO verdicts from both models.
44,112 are noncanonical links: 24,438 reviewed_yes and 19,674 reviewed_not_retained.
1,375 are canonical_retained links with completed reviews. Canonical retention is not equivalent to agreement by both judges.
The full source ledger contains 56,856 rows. It additionally contains 11,361 canonical links without verdicts and 8 incomplete noncanonical reviews; neither is counted as a completed review here.

The CSV includes occupation codes/titles, O*NET task IDs/statements, canonical status, both model verdicts and the reconciled status. It excludes posting text, incidence counts, sampling information and profile weights. It is a review-results release, not the full set of retained occupation-task links; eligible unreviewed links also enter the model. Support filtering is a separate step.
See review_protocol.json for the saved review prompt and models, and completed_review_export.json for source hash and counts. The earlier Evidence dashboard is an earlier review snapshot; this release includes additional links assessed under the same procedure.
