# Tasks in workplace incidents: task download guide

610 O*NET 27.2 tasks with activity documented in reviewed workplace incident narratives. Membership reflects AI-reviewed evidence of activity, not injury probability or a ranking of danger.

## Start here

Use dangerous_tasks.csv or dangerous_tasks.json for the task list. Join task_id to the O*NET 27.2 task inventory. task_description is the exact official description; evidence_status is ai_confirmed_incident_activity. No posting data are included.

## Interpretation

The historical_n_investigations and original_rank fields in the full review exports describe original candidate retrieval, not validated incident frequencies or danger rankings. The inventory includes unconfirmed and partial evidence; these are not members of the primary 610-task bundle. Review is AI-based, not human validation. The 610 historical positives include 19 IDs absent from O*NET 30.0 and one description mismatch. All 610 match O*NET 27.2 and remain in the compact list. The 30.0 files are compatibility subsets, not evidence exclusions.

## Provenance and code

Source: TaskMatchAccidents/results/onet_list_validation, source release dated September 27, 2026. Original exports are copied byte for byte. manifest.json records SHA-256 hashes. export_downloads.py builds the compact derivatives; it does not repeat the underlying AI review. See review_protocol.md and PROVENANCE.md for that procedure. Original release reports describe the 30.0 compatibility subset; this guide and the current benchmark methods document the full 610-task 27.2 bundle.
