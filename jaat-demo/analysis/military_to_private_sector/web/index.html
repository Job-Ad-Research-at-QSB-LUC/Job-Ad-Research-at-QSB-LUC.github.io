How to read this

Each Army entry retains its listed skill levels. Joint aviation specifications remain explicitly grouped. Marine entries include the applicable occupational-field introduction. Navy jobs include rating scope and listed CORE and NON-CORE task rows; paygrades remain in the source data. General Naval Standards are separate records, not silently attributed to every job.

JAAT 1.1.3 identifies candidate sentences and matches them to O*NET tasks using its native 0.87 threshold. The classifier score shown with each quotation is the task-versus-non-task classifier score, not a probability that the O*NET match is correct. Native sentence-length and token limits are disclosed in each record.

Civilian SOC/O*NET reference sections are withheld from model input and retained in the raw source text. The DMDC crosswalk is archived for a subsequent independent comparison. Crosswalk agreement would not establish observed veteran transition outcomes.

The Navy compilation is July 2026; individual chapters can have earlier update dates. The Marine manual is effective October 2025. Army effective dates vary and future-effective versions are flagged. These source sets are not a complete inventory of every branch, officer category, or specialty.
